NOTES
================================
- Passwords are stored as bcrypt hashes (never plain text).
- To change a user's password, regenerate a bcrypt hash:
  php -r "echo password_hash('NEWPASSWORD', PASSWORD_BCRYPT);"
  then update the password_hash value in the users table.
- Forgot password / additional accounts: manage under
  Admin > Settings > Users (once that module is built).
